# One Line of Wonder

A single line written to make a reader feel wonder. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` (one line, UTF-8) and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
